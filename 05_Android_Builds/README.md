# Android Builds (`05_Android_Builds/`)

Store compiled `.apk` files downloaded from [GitHub Actions](https://github.com/features/actions) here so each test build is versioned and easy to find on your phone (for example: `HIT-Connect-v1.0-debug.apk`).

See `../04_Documentation/ANDROID_SETUP_AND_DEPLOY_GUIDE.md` for step-by-step cloud build instructions.
